# DogGuide — проектирование (практика 1)

Приложение: **справочник пород собак**.  
Пакет: `ru.mirea.fedorov.dogguide`.

Гость смотрит каталог и может запустить распознавание. Пользователь после входа дополнительно сохраняет избранное в БД.

Внешний JSON: [Dog CEO API](https://dog.ceo/dog-api/) (без ключа).  
ML позже: TensorFlow Lite, классификация породы по фото.

## Акторы

- **Гость** — неавторизованный пользователь.
- **Пользователь** — обобщение гостя: те же действия плюс избранное и сохранение результата распознавания.

## Use case (соответствуют диаграмме)

| Модуль | Use case | Кто |
|--------|----------|-----|
| Аккаунт | Войти | Гость |
| Аккаунт | Зарегистрироваться | Гость |
| Аккаунт | Выйти | Пользователь |
| Каталог | Просмотреть список пород | Гость |
| Каталог | Просмотреть карточку породы | Гость |
| Каталог | Получить данные с API | include списка и карточки |
| Избранное | Добавить породу в избранное | Пользователь |
| Избранное | Просмотреть избранное | Пользователь |
| Избранное | Удалить из избранного | Пользователь |
| Распознавание | Распознать породу по фото | Гость |
| Распознавание | Сохранить результат | extend, только Пользователь |

## Экраны и зоны ответственности

Как в методичке (рис. 4–6): экран в presentation вызывает только domain use case. Реализация репозитория — data.

### Экран «Вход»

- presentation: форма логина / регистрации
- domain: `LoginUserUseCase`, `RegisterUserUseCase`
- data: `UserRepositoryImpl` (на этом этапе — тестовый пользователь)

### Экран «Список пород»

- presentation: список с изображениями
- domain: `GetBreedListUseCase`
- data: `BreedRepositoryImpl` (пока тестовые данные; позже JSON Dog CEO)

### Экран «Карточка породы»

- presentation: фото, название, описание, кнопка избранного
- domain: `GetBreedDetailsUseCase`, `AddBreedToFavoritesUseCase`
- data: `BreedRepositoryImpl`, `FavoriteRepositoryImpl`
- кнопка «В избранное» доступна только авторизованному

### Экран «Избранное» (только пользователь)

- presentation: список сохранённых пород
- domain: `GetFavoriteBreedsUseCase`, `RemoveBreedFromFavoritesUseCase`
- data: `FavoriteRepositoryImpl` (пока память; позже Room)

### Экран «Распознать породу»

- presentation: камера / галерея, результат
- domain: `RecognizeBreedUseCase`
- data: `RecognitionRepositoryImpl` (пока заглушка; позже TFLite)
- гость видит результат, пользователь может сохранить его

## Правило зависимостей

```
Presentation  →  Domain  ←  Data
```

Domain не знает про Android, Retrofit, Room, SharedPreferences, TFLite.  
Контракт репозитория живёт в domain, реализация — в data.
